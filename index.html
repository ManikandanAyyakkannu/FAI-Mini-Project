AI-Based University Enquiry Chatbot

An enquiry chatbot for the fictional Greenfield University, built with Knowledge Representation + NLP. There is no large language model inside. Every answer comes from a knowledge base or a rule, so it can always be explained.

How it works

  • Frames with inheritance: programmes, departments and facilities stored as a semantic network (is_a links).
  • Forward-chaining rules: 26 IF-THEN rules decide eligibility and scholarships, and explain every step.
  • NLP pipeline: abbreviation normalisation (B.E, M.Tech, plus two, CGPA), spelling correction, synonyms, stemming, entity extraction, intent classification.
  • Dialogue manager: follow-up questions ("How long is it?") and asking for missing details.
  • Vector store: TF-IDF search over FAQ passages for topics that are not in the frames.
