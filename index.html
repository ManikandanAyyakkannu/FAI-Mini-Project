AI-Based University Enquiry Chatbot

A complete enquiry chatbot for the fictional AI University, built with Knowledge Representation + NLP. It answers questions about the whole university: admissions and programmes, fees, the academic calendar, exams and results, certificates, university offices, departments, hostel, placements, events and research. There is no large language model inside. Every answer comes from a knowledge base or a rule, so it can always be explained.

How it works

  • Frames with inheritance: programmes, departments, offices, certificates, the academic calendar, exams and facilities stored as a semantic network (is_a links).
  • Forward-chaining rules: 26 IF-THEN rules decide eligibility and scholarships, and explain every step.
  • NLP pipeline: abbreviation normalisation (B.E, M.Tech, plus two, CGPA, sem), spelling correction, synonyms, stemming, entity extraction, intent classification (27 intents).
  • Dialogue manager: follow-up questions ("How long is it?", "Which office handles it?") and asking for missing details.
  • Vector store: TF-IDF search over FAQ passages for topics that are not in the frames.
  • Closed-world assumption: a department that is not in the knowledge base is not offered, and other universities are not covered, so the bot says so instead of guessing.
